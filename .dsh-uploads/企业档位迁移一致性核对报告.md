## 二、非实质差异说明

### 差异 1：tier_code 是否 NOT NULL
- 管理端：`NOT NULL DEFAULT 'enterprise'`（更严谨，签发时必带档位）
- 客户端：无 NOT NULL
- 影响：无。`get_license_payload` 中已用 `COALESCE(v_rec.tier_code, 'enterprise')` 兜底，旧行/缺失值均归企业。
- 建议：以管理端为准（NOT NULL 更符合"企业为默认档位"的语义），客户端无需回改。

### 差异 2：permission_summary 默认值
- 管理端：默认 NULL（语义为"未生成摘要"）
- 客户端：默认空串 `''`
- 影响：无。管理端签发页 `values.permission_summary || buildPermissionSummary(...)` 保证显式写入；Edge Function 传 `?? null`；客户端不消费该字段（仅展示用途）。
- 建议：无需统一，两值均被上层兜底。
