## 主题
Web 聊天框拖拽文件解析本地路径：浏览器无法直接读取拖入文件的绝对路径，非图片文件拖入即**上传落盘**到会话项目目录 `.dsh-uploads/`，再把该路径插入输入框（不做磁盘遍历）。

## 改动
- 拖放分流：图片走附件栏；非图片文件在光标处插入绝对本地路径（整块插入，多个路径按行分隔，自动补换行）。
- 路径优先取浏览器拖拽 URI-list（`text/uri-list` / `public.file-url`），解码 file:// URI（盘符 / POSIX / UNC / 百分号转义 / 片段剥离）——浏览器提供时瞬时插入**原路径**。
- 浏览器未提供路径时 → 新增 loopback 限定 RPC `host.uploadDroppedFile`：把 base64 字节写入 `<cwd>/.dsh-uploads/<文件名>`（重名加数字后缀去重），返回写入路径；`cwd` 限宿主启动目录或已注册工作区，单文件上限 20 MB，不做磁盘遍历。
- 上传中显示不定态 spinner + 「正在上传文件…」；失败提示带出具体文件名。
- 拖放遮罩文案由「图片」改为「文件」（`drop.*` 键）。
- （过程中的中间方案——按名称+大小遍历工作区/常用目录搜索原路径——已废弃，因参考文件只读、无需找回原位置。）

## 注意事项
- 宿主端代码改动需重启 `dsh web` 才生效；纯客户端改动 Ctrl+F5 强刷即可。
- Chrome（Windows 实测）从资源管理器拖拽不提供 `text/uri-list`，故实际主要走上传落盘路径。
- 拖入的参考文件是**副本**（在 `.dsh-uploads/`），只读参考场景适用；要改原件需 agent 的 filesystem 工具针对原位置操作。
- 本会话运行中的后端进程即承载 agent 自身，无法由 agent 自行重启，需用户手动重启。
